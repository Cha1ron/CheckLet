CheckLet 安装说明
================

1. 把 CheckLet 拖进「Applications / 应用程序」文件夹。

2. 第一次打开（因为没有上架 App Store，macOS 会拦一下）：
   - 双击 CheckLet，看到"无法打开"的提示时点「完成」；
   - 打开「系统设置 → 隐私与安全性」，往下翻，点 CheckLet 旁边的「仍要打开」，输入密码确认。
   或者，打开「终端」粘贴下面这行并回车，然后正常双击打开：
       xattr -cr /Applications/CheckLet.app

3. 打开后屏幕右侧会出现一个半透明小球，菜单栏也会有 ☑︎ 图标：
   - 鼠标移到小球上 → 显示待办；点小球 → 固定显示
   - 快捷键 ⌃⌥T（Control + Option + T）→ 固定显示并直接输入，再按一次隐藏
   - 拖动小球可换位置；右键小球或点菜单栏图标 → 设置

4. 连接 AI 工具：设置 → AI 连接 → 一键连接 Claude Desktop / Claude Code / Codex。
   连接后重启对应的 AI 工具，就可以说"把明天交报告加到我的待办"了。
